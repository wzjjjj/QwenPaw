## 核心概念

### 命令处理流程

命令处理流程包括以下步骤：

1. **命令解析**：解析用户输入，识别命令类型和参数
2. **命令路由**：根据命令类型和上下文选择合适的处理程序
3. **命令执行**：执行命令并获取结果
4. **结果处理**：处理命令执行结果，返回给用户

### 命令类型

QwenPaw 支持多种类型的命令：

1. **内置命令**：系统内置的命令，如 `help`、`clear` 等
2. **工具命令**：调用工具的命令，如文件操作、浏览器控制等
3. **技能命令**：调用技能的命令，如 PDF 处理、新闻摘要等
4. **代理命令**：控制代理行为的命令，如切换代理、查看状态等

### 安全控制

命令执行的安全控制包括：

1. **命令白名单**：只允许执行安全的命令
2. **权限检查**：检查用户是否有执行命令的权限
3. **参数验证**：验证命令参数的合法性
4. **执行环境隔离**：在隔离的环境中执行命令
